ServiceNow: "New After Action Report" Button Fix

Issue Fixed

In ServiceNow Service Operations Workspace (Zurich), the "New" button was missing from Problem records for creating After Action Reports. This button existed in Xanadu but was removed in Zurich.

This fix restores the missing button functionality.

Installation Required

To enable this button in your ServiceNow instance, import the provided update set:

  1. Navigate to System Update Sets > Retrieved Update Sets
  2. Click Import Update Set from XML
  3. Upload update_set_after_action_report_new_button.xml
  4. Preview and Commit the update set
  5. Verify the button appears on Problem records
